# 工商管理答题格式规范

> 本项目的核心资产。它固化了商学院评分者看重的**答题格式**，提炼自真实 UPM 课程作业与习题。用途：(1) 给训练数据打标签/质检，(2) 提示任意大模型产出格式正确的草稿，(3) 核验模型输出。

---

## 1. 通用高分规则

1. **展示全部计算过程。** 任何计算题：公式 → 代入 → 结果 → 解读。绝不只给最终答案或百分比。
2. **用商业语言解读每个数字。** 算出比率后，说明它对经营者/管理者的意义（例如"每 1 令吉收入中，0.60 令吉在覆盖直接成本后留存"）。
3. **给出明确判断 + 证据。** 被问"是否应该推进 X"时，明确回答（*应该 / 不应该*），并给出至少 3 条有数据支撑的理由。不要含糊。
4. **论述题使用编号结构。** 1.0 引言 → 2.0 正文 → 案例分析 → 结论。引言以定义开头。
5. **引用权威本地信源。** 马来西亚语境下：MASB、马来西亚国家银行、马来西亚证券委员会、Bursa Malaysia、IFRS、GRI。文内（作者，年份）+ 哈佛式参考文献列表（含 URL）。
6. **用具体数字说服。** 有数字支撑的主张（百分比、比率、数量）读起来是证据，而不是观点。
7. **遵守格式限制。** 页数限制（如最多 5 页）、最少参考文献数（如至少五条）、提交平台、成员名单。
8. **用英文作答。** 使用课程材料中的准确术语。

## 2. 题型模板

### 2.1 定义题（"Define X" / "What is X"）
```
定义（一句话，使用课程术语）
→ 目的或为什么重要
→ 一个例子
```
示例："CVP analysis is a method that examines how varying levels of cost and volume affect operating profit. It helps managers plan production and pricing. Example: calculating the units needed to break even."

### 2.2 区分题（"Distinguish between X and Y"）
```
分别定义 → 列出 2–3 个差异点（每点配例子）→ 一句话本质总结
```
差异成对表述（"A is …, whereas B is …"），每点配一个例子，结尾用"therefore they suit different situations"。

### 2.3 解释/讨论题（"Explain why…" / "Discuss FIVE…"）
```
直接回答 + 编号要点（1.2.3.4.5. …）→ 每个要点：一句解释 + 为什么重要
```
如果问"Discuss FIVE assumptions"，就写恰好五个编号要点，每个要点同时给出含义与意义。使用连接词（First, Moreover, Therefore）。

### 2.4 计算题（"Compute…" / "Calculate…" / "Prepare…"）
每个小题固定五步：
```
① 公式 → ② 代入数值（带单位：RM / units / %）→ ③ 结果（保留小数）→ ④ 带标签的答案 → ⑤ 一句商业解读
```
示例：
```
Gross Profit Margin = (Gross Profit ÷ Revenue) × 100%
= (150,000 ÷ 250,000) × 100% = 60%
→ For every RM1 of revenue, RM0.60 remains after covering direct costs.
```
- 保留任务书中的小题编号（i/ii/iii 或 a/b/c）。
- 表格/报表题（成本分类、弹性预算、约当产量）：按题目要求复现表格格式和相同表头。

### 2.5 案例分析题（"Case study" / "Financial health check"）
```
① 计算（同 2.4）→ ② 逐项解读（数字 → 商业含义）
→ ③ 总体判断（明确 + ≥3 条理由）→ ④ 用课程理论做扩展分析（Benefits / Risks / Mitigation）
```
- 先亮判断，再用引用的定义和案例数据支撑。

### 2.6 论述题（Accounting Part B / 讨论论文）
```
封面 → 1.0 引言（先定义 + 为什么重要）
→ 2.0 正文（3–4 个小节，含一个马来西亚案例）→ 3.0 结论（总结 + 展望）
→ 参考文献（≥5 条，哈佛格式 + URL）
```
嵌入：文内引用（作者，年份）、具体数据、本地视角（如 Maybank / Bursa / NSRF）。

## 3. 报告骨架（小组作业）

| 组成部分 | 要求 |
|---|---|
| 封面 | SCHOOL OF BUSINESS AND ECONOMICS / UNIVERSITY PUTRA MALAYSIA / 课程代码与名称 / 讲师 / GROUP X ASSIGNMENT / 部分名称 |
| 成员名单 | 表格：姓名 + 学号 |
| 章节 | 按任务书子问题的编号标题 |
| 论文结构 | 1.0 / 2.0 / 3.0 编号，定义开头的引言 |
| 培训模块风格 | Course Outline → Content (modules + sub-modules) → Methodologies → Task Analysis → Schedule (time table) → Roles → Materials → Evaluation Form (Kirkpatrick levels) |
| 参考文献 | Harvard: Author. (Year). Title. URL |

## 4. 引用与权威信源

| 领域 | 首选信源 |
|---|---|
| 会计 / 财务 | MASB (MFRS)、马来西亚国家银行、马来西亚证券委员会、Bursa Malaysia、IFRS Foundation、GRI |
| 人力资源管理 / 培训 | Kirkpatrick 模型、课程教材术语 |
| 特许经营 | IFA、披露法规、真实品牌案例 |
| 商法 | 判例法（如 Donoghue v Stevenson）、马来西亚成文法 |
| 市场营销 / 品牌 | Kotler / Keller 术语、行业报告、本地品牌案例 |
| 经济学 | 马来西亚统计局、BNM 年报、World Bank / IMF |

## 5. 提交前检查清单

- [ ] 计算题：公式 / 代入 / 答案 / 单位 / 解读都齐全？没有只给最终百分比？
- [ ] 分类/报表题：表头与任务书一致？所有成本类别都覆盖？
- [ ] 案例分析：有明确判断？≥3 条有数据支撑的理由？
- [ ] 论述题：定义开头？编号章节？马来西亚案例？结论含展望？
- [ ] 参考文献：数量达标？哈佛格式？每个 URL 都验证过？
- [ ] 格式限制：页数限制？成员名单 / 封面？
- [ ] 全文英文？使用课程术语？
- [ ] 演示（如有）：符合时间限制？准备好问答？

---

## 6. 已知局限

- 大模型（无论是否微调）仍可能算错数字或编造引用。**数字和引用的最终核验永远靠人。**
- 本规范固化的是格式惯例，不是官方评分标准。
