# data/raw/ — 版权与隐私清洗规则

本目录只存放**清洗后、无版权、无隐私**的原始整理材料，用于构建 `train.jsonl`。

## 上传前必须遵守

1. **禁止**直接上传出版社教材、学校内部讲义、课程幻灯片原文（受版权保护）。
2. **禁止**包含作业成员姓名、学号、邮箱等个人信息。
3. 只放以下内容：
   - 你自己原创写的答题格式规范与示例
   - 通用商科知识（教科书常见概念的定义/公式，非逐字复制）
   - 标注了来源的公开事实（给出链接即可，不复制大段原文）
4. 每个文件建议以 `SOURCE_说明` 开头注明材料性质和整理方式，便于他人信任数据来源。

## 工作流

1. 把原始课件/作业材料在**本地**整理成指令对草稿。
2. 只将**清洗后**的整理稿放入本目录。
3. 运行 `python build_dataset.py` 生成 `train.jsonl`。
4. 提交前自查：`python build_dataset.py --validate`。

> 原则：别人拿到这个仓库后，应当能通过 `docs/answering-guide.md` 和本目录数据**复现你的整理流程**，同时不触犯任何版权或隐私边界。
